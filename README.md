# Tabbit 标签兔 🐇

[简体中文](README.md) · [English](README_EN.md)

[![CI](https://github.com/xichengpro/tabbit/actions/workflows/ci.yml/badge.svg)](https://github.com/xichengpro/tabbit/actions/workflows/ci.yml)

一只会在网页上散步、也会感受标签页节奏的小兔子。

Tabbit 不会评价你的效率，也不会催你清空所有标签页。它把标签页数量、短时间内打开新页面的速度、长期未访问页面的比例，以及同时播放声音的页面数量，变成一只小兔子的心情，让杂乱的浏览空间变得更容易感知。

> 当前版本为 `0.1.0` 原型，适合开发者体验和反馈，尚未发布到 Chrome Web Store。

## 你会看到什么

- **会变化的标签兔**：平静、好奇、忙碌、被标签页埋住，四种状态都有不同颜色和动画。
- **真的会到处跑**：小兔子会在普通网页中自由散步；左键点它会逃跑，右键可以选中并打开控制菜单。
- **更自然也不挡字**：使用连续的小步移动，并优先选择不穿过、也不覆盖可见文字的路线；透明度可在 30%–100% 间调整。
- **多种情绪动作**：它会挥手、跳跃、打盹、紧张抖耳朵，也会根据当前心情说不同的话。
- **旧标签提醒**：检测到长时间未访问的标签页时，会用页面气泡温和提醒；可随时单独关闭。
- **看得懂的原因**：不仅显示负载数字，也会告诉你主要来自标签页数量、连续打开、长期未访问或多页面发声。
- **一分钟完成领养**：给小兔子起名，并选择适合自己的轻装、日常或重度浏览节奏。
- **温和的提醒**：标签页多不等于效率低。Tabbit 只描述状态，不批评、不惩罚，也不会让宠物生病或死亡。
- **尊重减少动画设置**：支持系统 `prefers-reduced-motion`，也可以在设置页手动关闭动画。

## 隐私是默认设置

Tabbit 的基础宠物功能不读取：

- 网页正文或表单内容
- 标签页标题和网址
- 浏览历史
- 账号、邮件或身份信息

所有宠物状态和设置只保存在当前浏览器中，不需要注册，不连接业务后端，也不会上传浏览数据。

为了让小兔子出现在网页上，Tabbit 的内容脚本会在普通 `http://` 和 `https://` 页面中创建一个隔离的 Shadow DOM 图层。为了尽量避开文字，它只在候选落点上检测字符的渲染矩形，不读取、保存或上传字符内容；它也不读取标题、网址、表单和输入内容，不会运行在 `chrome://` 等浏览器内部页面。网页小兔子可在右键菜单或设置页中关闭。

扩展默认只请求三个权限：

| 权限 | 用途 |
| --- | --- |
| `sidePanel` | 在 Chrome 侧边栏显示标签兔 |
| `storage` | 在本地保存名称、设置和宠物状态 |
| `alarms` | 每分钟进行一次低频状态校正 |

整理标签页时，才会在你点击授权后请求可选的 `tabs` 权限。它只用于在当前浏览器中读取标签标题、网址、活动时间和固定/发声状态，生成可手动选择的候选项；不上传到任何服务。使用网站聚合时，只有再次授权 `tabGroups` 后才会创建浏览器原生标签组。关闭标签后，所选标签的网址、原窗口和顺序会在本地保留最多 24 小时，供你一键恢复，随后自动过期。

这三个是默认 Manifest API 权限，`tabs` 是按需申请的可选权限；网页小兔子的内容脚本匹配范围固定为 `http://*/*` 和 `https://*/*`，没有额外的 `host_permissions`。每次构建都会同时核对默认权限、可选权限和内容脚本范围，未审查的变化会让 CI 失败。

## 从源码体验

需要 Chrome 114+、Node.js 22 和 npm。

```bash
git clone https://github.com/xichengpro/tabbit.git
cd tabbit
npm ci
npm run build
```

然后：

1. 打开 `chrome://extensions`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择项目中的 `.output/chrome-mv3` 目录。
5. 点击浏览器工具栏里的 Tabbit 图标，侧边栏会自动打开。

第一次打开时，Tabbit 会带你完成三步领养。领养完成后刷新一个普通网页，就能看到小兔子出来散步：左键点它会逃跑，右键点它可开关旧标签提醒、进入完整设置或收起小兔子。关闭后可在设置页重新开启。

## 心情是怎样计算的

Tabbit 只使用聚合数字计算浏览负载，并将结果限制在 0–100：

| 因素 | 影响权重 |
| --- | ---: |
| 标签页数量 | 55% |
| 10 分钟内新开标签页 | 25% |
| 长期未访问标签页比例 | 15% |
| 正在发声的标签页 | 5% |

心情变化带有防抖和滞后保护，因此连续打开或关闭页面时，小兔子不会在临界值附近反复闪烁。

已经可用：

- 侧边栏宠物主页和三步领养
- 网页自由散步、左键逃跑和右键控制菜单
- 挥手、跳跃、打盹、警觉等情绪动作
- 带 30 分钟冷却的长期未访问标签页提醒
- 实时浏览负载与原因说明
- 安全整理标签页：手动选择候选项、预览并二次确认关闭、24 小时内恢复
- 网站聚合：按域名和窗口把多个未受保护标签加入浏览器原生标签组
- 四状态 SVG 动画与减少动画支持
- 本地设置、版本化存储、迁移与异常数据保护
- 中文情绪文案、夜间文案和六小时防重复
- 自动类型检查、单元测试、构建、权限审计和构件上传

正在规划：

- 25 分钟专注计时与完成庆祝
- 更完整的装饰和成长系统
- 用户自定义宠物照片或动图（本地上传、校验和恢复默认）

“开始专注”仍是功能预告；“整理标签页”已可使用。进入后先授权，再查看未默认勾选的候选标签，选择、预览并确认后才会关闭。

## 常见问题

**为什么我的标签页很多，Tabbit 却不批评我？**

因为它是陪伴型工具，不是效率评分器。你可以在领养或设置中选择更适合自己的阈值。

**它会自动关闭标签页吗？**

不会自动关闭。整理页只会展示候选项，默认不选择任何标签；你需要手动选择、预览并再次确认。活动、固定、正在发声和最近 10 分钟使用过的标签不会成为候选项。已关闭的选择可在 24 小时内恢复。

**怎样暂时关闭网页上的小兔子？**

右键点小兔子，选择“收起网页小兔子”。之后可在 Tabbit 设置页重新开启；旧标签提醒也可以单独关闭。

**卸载后数据还在吗？**

Chrome 通常会删除扩展的本地存储。当前版本还没有云同步或账号恢复功能。

**为什么没有商店安装链接？**

项目仍处于原型验证阶段。完成真实浏览器验收、可访问性检查和隐私材料后才会提交商店。
