# Tabbit 标签兔

> 一只住在浏览器侧边栏、会感知标签页节奏的小兔子。

Tabbit 把标签页数量、短时打开速度、长期未访问页面和音频标签等**聚合状态**转化为宠物的心情。它用温和、有趣的反馈帮助用户整理浏览空间，而不是用分数批评用户。

## 当前状态

仓库处于 `0.1.0` 产品原型阶段，已经包含：

- Manifest V3 扩展工程骨架
- Chrome Side Panel 宠物主界面
- 事件驱动的标签页快照采集
- 可测试的“浏览负载 → 宠物心情”规则引擎
- 本地设置与状态存储
- 四状态本地 SVG sprite 原型和减少动画支持
- 类型化 zh-CN 文案目录、夜间文案与六小时 flavor 轮换
- 产品、交互、技术、测试和交付文档

目前使用四状态 SVG sprite 原型；正式开发时可替换为完整 9 状态 sprite 资源。

## 核心原则

1. **先好玩，再有用**：打开侧边栏时先看到角色反馈，数据退居第二层。
2. **不羞辱用户**：宠物不会生病、死亡或指责用户；高负载只表示需要帮助。
3. **默认隐私**：MVP 不读取网页正文、标题、URL、表单、历史记录，也不上传数据。
4. **用户掌控**：任何关闭、移动、分组标签页的动作都需要预览和确认。
5. **低打扰**：没有默认通知，不在网页中自动注入漂浮组件。

## 技术栈

- Chrome/Edge 扩展，Manifest V3
- [WXT](https://wxt.dev/) + React + TypeScript
- `chrome.sidePanel`、`chrome.tabs`、`chrome.storage`、`chrome.alarms`
- Vitest；E2E 计划使用 Playwright
- MVP 无后端、无登录、无远程代码

Chrome 114+ 是首发目标。Edge 和 Firefox 在核心体验稳定后适配。

## 开始开发

```bash
npm install
npm run dev
```

然后在 Chrome 中打开 `chrome://extensions`：

1. 开启“开发者模式”。
2. 选择“加载已解压的扩展程序”。
3. 选择 WXT 生成的 `.output/chrome-mv3` 目录。
4. 点击工具栏的 Tabbit 图标打开侧边栏。

常用命令：

```bash
npm run typecheck
npm test
npm run build
npm run zip
```

每次向 `main` 推送或提交 Pull Request 时，GitHub Actions 会自动执行类型检查、单元测试、构建和 Manifest 权限审查，并上传可直接加载的未压缩扩展产物。当前仓库不配置自动发布。

## MVP Definition of Done

- 新用户 60 秒内完成领养并看到宠物对当前标签页状态作出反应。
- 标签页创建、关闭、激活后，侧边栏状态在 2 秒内更新。
- Chrome 重启后宠物名称、等级、设置和奖励保留。
- 无 `tabs`、历史记录、网页主机权限；网络面板中无业务数据外传。
- 空窗口、1000 个标签页、多个窗口、浏览器休眠恢复均不崩溃。
- 核心规则单元测试通过，构建包可在 Chrome 114+ 加载。
- 完成隐私政策、商店截图、权限说明和人工冒烟测试。
