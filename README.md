# Tabbit 标签兔 🐇

[简体中文](README.md) · [English](README_EN.md)

[![CI](https://github.com/xichengpro/tabbit/actions/workflows/ci.yml/badge.svg)](https://github.com/xichengpro/tabbit/actions/workflows/ci.yml)

一只住在浏览器侧边栏、会感受标签页节奏的小兔子。

Tabbit 不会评价你的效率，也不会催你清空所有标签页。它把标签页数量、短时间内打开新页面的速度、长期未访问页面的比例，以及同时播放声音的页面数量，变成一只小兔子的心情，让杂乱的浏览空间变得更容易感知。

> 当前版本为 `0.1.0` 原型，适合开发者体验和反馈，尚未发布到 Chrome Web Store。

## 你会看到什么

- **会变化的标签兔**：平静、好奇、忙碌、被标签页埋住，四种状态都有不同颜色和动画。
- **看得懂的原因**：不仅显示负载数字，也会告诉你主要来自标签页数量、连续打开、长期未访问或多页面发声。
- **一分钟完成领养**：给小兔子起名，并选择适合自己的轻装、日常或重度浏览节奏。
- **温和的提醒**：标签页多不等于效率低。Tabbit 只描述状态，不批评、不惩罚，也不会让宠物生病或死亡。
- **尊重减少动画设置**：支持系统 `prefers-reduced-motion`，也可以在设置页手动关闭动画。

## 隐私是默认设置

Tabbit 的 MVP 不读取：

- 网页正文或表单内容
- 标签页标题和网址
- 浏览历史
- 账号、邮件或身份信息

所有宠物状态和设置只保存在当前浏览器中，不需要注册，不连接业务后端，也不会上传浏览数据。

扩展目前只请求三个权限：

| 权限 | 用途 |
| --- | --- |
| `sidePanel` | 在 Chrome 侧边栏显示标签兔 |
| `storage` | 在本地保存名称、设置和宠物状态 |
| `alarms` | 每分钟进行一次低频状态校正 |

每次构建都会自动核对最终 Manifest；新增权限会让 CI 失败，必须经过明确审查。

## 从源码体验

需要 Chrome 114+、Node.js 22 和 npm。

```bash
git clone https://github.com/xichengpro/tabbit.git
cd tabbit
npm ci
npm run build
```

然后：

1. 打开 `chrome://extensions`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择项目中的 `.output/chrome-mv3` 目录。
5. 点击浏览器工具栏里的 Tabbit 图标，侧边栏会自动打开。

第一次打开时，Tabbit 会带你完成三步领养。之后可以在设置页调整舒适数量、拥挤数量和动画偏好，也可以重新进入领养流程。

## 心情是怎样计算的

Tabbit 只使用聚合数字计算浏览负载，并将结果限制在 0–100：

| 因素 | 影响权重 |
| --- | ---: |
| 标签页数量 | 55% |
| 10 分钟内新开标签页 | 25% |
| 长期未访问标签页比例 | 15% |
| 正在发声的标签页 | 5% |

心情变化带有防抖和滞后保护，因此连续打开或关闭页面时，小兔子不会在临界值附近反复闪烁。

已经可用：

- 侧边栏宠物主页和三步领养
- 实时浏览负载与原因说明
- 四状态 SVG 动画与减少动画支持
- 本地设置、版本化存储、迁移与异常数据保护

## 常见问题

**为什么我的标签页很多，Tabbit 却不批评我？**

因为它是陪伴型工具，不是效率评分器。你可以在领养或设置中选择更适合自己的阈值。

**它会自动关闭标签页吗？**

不会。当前版本完全不会关闭、移动或分组标签页；未来的整理功能也会要求用户确认。

**卸载后数据还在吗？**

Chrome 通常会删除扩展的本地存储。当前版本还没有云同步或账号恢复功能。

**为什么没有商店安装链接？**

项目仍处于原型验证阶段。完成真实浏览器验收、可访问性检查和隐私材料后才会提交商店。
