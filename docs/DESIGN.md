# Tabbit 交互与视觉设计方案

## 1. 体验目标

用户打开 Tabbit 后，理想反应依次是：

1. “这只兔子现在怎么了？”——角色引发好奇；
2. “原来是因为我刚开了很多标签。”——反馈可解释；
3. “我顺手整理几个吧。”——形成低成本行动；
4. “它居然庆祝了。”——得到情绪回报；
5. “下次再看看它。”——建立自然回访。

设计重点不是呈现更多管理功能，而是缩短从“看见状态”到“愿意做一个小动作”的距离。

## 2. 信息架构

### Side Panel：日常主界面

从上到下固定为五层：

1. **身份层**：宠物名称、等级、设置入口；
2. **情绪层**：占据约 50% 高度的角色栖息地；
3. **解释层**：负载和 1–3 个原因；
4. **行动层**：一个主行动、一个次行动；
5. **成长层**：XP、树叶和最近解锁。

### Options：低频设置

- 宠物：名称、装饰、重新领养；
- 浏览舒适区：阈值、陈旧时长；
- 专注：默认时长、完成提醒；
- 安静模式：静默时段、减少动画、声音；
- 隐私与数据：已授权权限、导出、重置、隐私说明；
- 关于：版本、反馈、开源/许可状态。

### 整理页（P1）

使用独立扩展页而不是塞进狭窄侧边栏，以便展示清单、选择和恢复入口。页面必须保持“候选 → 手动选择 → 确认”三段结构。

## 3. Side Panel 线框规格

| 区域 | 高度/布局 | 内容 | 交互 |
| --- | --- | --- | --- |
| 顶栏 | 56 px，左右布局 | 等级、名称、设置 | 设置按钮 44 px 热区 |
| 栖息地 | 最低 260 px，居中 | 宠物、环境、气泡 | 点击宠物触发 1 个轻互动 |
| 状态卡 | 自适应，16 px 内边距 | 负载条、主因、说明 | 展开查看计算原因 |
| 行动区 | 两行全宽按钮 | 专注、整理 | 主按钮随上下文变化 |
| 页脚 | 32 px | 树叶、XP | 点击进入收藏册（P1） |

窄至 320 px 时不允许横向滚动。高于 720 px 时增加栖息地留白，不继续堆功能。

## 4. 角色设计

### 4.1 角色设定

- 物种：圆耳短尾兔；
- 性格：好奇、可靠、偶尔手忙脚乱；
- 年龄感：年轻但不婴幼儿化；
- 关系：陪伴者，不是监督者；
- 世界观：标签页是从森林里飘来的纸片、叶子和小门。

默认名“团团”，首次使用鼓励用户重命名。品牌名 Tabbit 与角色名分离，以便未来提供多宠物。

### 4.2 必需动画状态

| 状态 | 循环动作 | 入场动作 | 时长建议 |
| --- | --- | --- | ---: |
| 平静 | 呼吸、眨眼、晃耳朵 | 坐下 | 3–5 秒循环 |
| 好奇 | 探头、闻纸片 | 从边缘跳入 | 2–4 秒循环 |
| 忙碌 | 抱着纸片分类 | 接住落下纸片 | 2–3 秒循环 |
| 被埋住 | 耳朵露在纸堆外 | 纸片落下 | 2–3 秒循环 |
| 专注 | 戴耳机写字 | 戴上耳机 | 3–5 秒循环 |
| 庆祝 | 抛叶子、转一圈 | 跳起 | 6–8 秒一次性 |
| 睡眠 | 蜷缩、呼吸 | 铺小毯子 | 4–6 秒循环 |
| 互动 | 跟随点击、挥手 | 用户点击触发 | <1.5 秒 |
| 升级 | 发光、拿出新物品 | 自动触发 | 5–8 秒一次性 |

资产建议：首版使用 2D sprite sheet，每状态 8–16 帧，导出 1×/2× WebP 或 PNG；避免把核心动画依赖于远程资源。单套角色压缩后目标 <1.5 MB。

### 4.3 减少动画模式

- 自动跟随系统设置，也允许用户覆盖；
- 循环动画变为静态关键帧；
- 庆祝从位移/旋转改为一次颜色和装饰变化；
- 数值变化不使用快速跳动；
- 不闪烁，不使用每秒 3 次以上的亮度变化。

## 5. 视觉语言

### 5.1 方向

关键词：温暖、轻巧、自然、桌面玩具、不过分幼稚。

避免：过度霓虹、游戏平台式 HUD、红色警报、连续红点、写实毛发和复杂 3D。

### 5.2 色彩 Token

| Token | 色值 | 用途 |
| --- | --- | --- |
| `ink` | `#27322C` | 正文 |
| `muted` | `#627069` | 次要信息 |
| `leaf-700` | `#294F3D` | 主按钮 |
| `leaf-400` | `#7BBF7A` | 正向状态 |
| `cream` | `#F7F4EA` | 页面背景 |
| `sun` | `#FFF0B9` | 好奇/探索 |
| `peach` | `#FAC7A9` | 忙碌 |
| `lavender` | `#E8D4F2` | 被埋住，替代危险红色 |
| `sky` | `#CCE7E8` | 专注/平静 |

所有文本组合达到 WCAG AA；颜色只做辅助，状态同时由角色、文字和图标表达。

### 5.3 排版与形状

- 系统圆体优先：`Inter, ui-rounded, SF Pro Rounded, system-ui`；
- 正文 13–15 px，标题 22–28 px；
- 主卡片圆角 24–28 px，普通卡片 14–18 px；
- 主按钮高度 ≥44 px；
- 阴影低对比，避免玻璃拟态影响可读性。

## 6. 状态文案矩阵

文案由 `mood × cause × timeOfDay` 决定，但每次只显示一句。相同文案 6 小时内不重复。

| 状态 | 首选文案 | 主行动 |
| --- | --- | --- |
| 平静 | “桌面很清爽，适合专心做一件事。” | 开始专注 |
| 好奇 | “我闻到了几个新标签页的味道。” | 看看节奏 |
| 忙碌 | “今天这里有点热闹。” | 整理 5 个 |
| 被埋住 | “救救我——先整理五个就很棒。” | 开始小整理 |
| 专注 | “我替你守着门。” | 暂停/结束 |
| 庆祝 | “呼！又看见桌面啦。” | 查看奖励 |
| 睡眠 | “今天先到这里也可以。” | 保持安静 |

晚上 23:00 后避免“开始专注”等促使继续工作的主行动，替换为“明天再整理”。

## 7. 领养流程

### Step 1：建立关系

- 标题：“有只小家伙想住进你的侧边栏”；
- 展示平静动画；
- 说明不用注册、默认不读取网页内容；
- 主按钮：“认识一下”。

### Step 2：命名

- 默认值“团团”，输入 1–12 字符；
- 角色对名字作出挥手反馈；
- 不要求唯一，不向服务器校验。

### Step 3：选择舒适区

- 轻装：10 舒适 / 30 拥挤；
- 日常：20 / 50；
- 重度：50 / 120；
- 自定义：5–300；
- 文案：“这只是团团适应你节奏的方式，随时能改。”

### 完成

展示当前真实聚合状态和第一句回应。隐私解释不应藏在长协议中。

## 8. 专注体验

- 开始前只选择时长，不要求填写任务；
- 倒计时只在面板打开时逐秒渲染，后台保存绝对结束时间；
- 标签继续增加时不打断专注状态；
- 结束时一次庆祝，可领取奖励；
- 提前结束不显示失败，文案为“这段时间先收好，需要时再来”；
- 每日奖励达到上限后仍可使用计时，只是不再发货币。

## 9. 整理体验（P1）

### 权限说明页

请求 `tabs` 前用三句话说明：

1. 为了找出重复或长期没看的标签，Tabbit 需要临时查看标签的标题和地址；
2. 分析只在设备本地进行，不上传；
3. 你可以随时关闭权限，基础宠物功能仍可使用。

### 候选规则

- **长期未访问**：超过用户设置时长；
- **完全重复**：标准化后 URL 相同，保留最近访问者；
- **同域聚集**：仅做折叠显示，不默认建议关闭；
- 排除当前活动、固定、发声、系统页、扩展页和最近 10 分钟打开的标签。

### 操作保护

- 默认不勾选；
- 每个候选显示理由；
- 确认页按窗口分组展示；
- 先保存恢复快照，再调用关闭 API；
- 完成页保留 24 小时“恢复刚才的标签”；
- 恢复后不扣除已经获得的 XP，但不再次发奖。

## 10. 通知与声音

- 默认全部关闭；
- 用户开启后只允许：专注结束、用户明确预约的休息提醒；
- 绝不因为标签过多发送系统通知；
- 声音独立开关，默认关闭；
- 静默时段覆盖通知和声音，但不影响本地计时完成记录。

## 11. 错误与空状态

| 场景 | 表现 |
| --- | --- |
| 首次计算未完成 | 宠物探头 + “正在认识你的浏览器” |
| 浏览器 API 暂时失败 | 保留旧状态 + “刚才走神了一下，稍后再看” |
| 存储损坏 | 使用默认值恢复，提供导出诊断信息 |
| 可选权限被撤回 | 隐藏 URL 类功能，基础状态继续工作 |
| 当前只有一个标签 | 平静状态，不建议继续关闭 |
| 1000+ 标签 | 只展示聚合数，不渲染完整列表 |
| 无网络 | 无变化；MVP 所有功能照常使用 |
